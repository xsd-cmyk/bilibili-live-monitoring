# 0622.11 · 卡片材质验收

## 范围

在 Android 15/API 35 专用模拟器上使用合成壁纸与合成列表；未用真实账号或用户配置。外观设置的 `liquid_glass_cards` 属于 DataStore，不改业务备份和 Room。

## 检查与结果

- 从上一版覆盖安装后默认不开新材质。实际从「设置 → 外观与主题 → 液态玻璃」尝试：普通导航、0dp 模糊，只打开新开关；强制停止并重开仍启用，首页、卡片点击进入的主播详情和不带底栏的设置子页均能显示。再从界面关闭，开关值落盘为关。[首页与主播详情实拍](card-examples.jpg)。
- `LiquidCardInstrumentedTest`：在同一窗口用双色背景、单独开启卡片，`PixelCopy` 在普通卡上取两点：开启后能看到不同的背景色，关闭后两点恢复到原始像素。重建仓储后重读快照，两方向写入新开关，其他设置完全相等。
- 页面内容 `AppCard`、浮动标题/搜索/筛选等 `FloatingCard` 和设置项中的卡片外壳经过同一材质入口。状态指示、头像、色块、按钮保留原角色，不把其内容作为材质输入。深色、12dp 模糊、原磨砂标志和新材质与玻璃 Dock 同时打开，滚动与切页正常。
- 同包 `:app:testDebugUnitTest` 379/379，Android 全套 instrumentation 92/92，`:app:lintDebug` 0 错误。早期全屏抓图尝试中模拟器进程异常退出，改从窗口用 `PixelCopy` 取样后，两项卡片测试及最终全套均通过。
- 未逐屏人工验收每种卡片；未在 API 31/32 或真机 GPU 上测功耗／帧率，不将 API 35 的画面视作这些设备的实测。
