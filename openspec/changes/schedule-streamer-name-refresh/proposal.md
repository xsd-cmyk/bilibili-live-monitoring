# 主播名称按周期刷新

## Why

每次有效直播观察都可能写回昵称；当前 SQL 忽略 null，却接受空白字符串。用户因此可能在通知等界面看到「主播」而不是之前的名称；首次添加缺名还可能把占位文字锁定，后续无法自动补全。

## What Changes

- 设置页提供两个独立间隔：正常更新默认 24 小时，获取失败默认 1 分钟重试。成功的主播不陪同失败项重试。
- 已有有效名称在失败时保持不变；从未取到名称时才使用占位。保留用户手动命名，名称刷新不触发开关播判断。
- 增加「立即重新获取所有主播名称」按钮，不受列表筛选或正常周期限制，显示更新、待重试与跳过数量。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `streamer-management`：为列表中的主播维护可靠的名称，并支持按周期、失败重试和手动全量获取。

## Impact

涉及主播添加与导入、详情资料刷新、监控事务中的资料写入、Room 设置与调度状态、设置页及业务备份兼容。复用匿名批量接口；不改变直播轮询频率、房间封面更新、用户权限或通知资格。
