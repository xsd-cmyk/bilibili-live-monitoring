## 2. 名称获取与调度

- [x] 2.1 接入匿名批量名称查询并按 UID 校验；用固定响应测试空白、缺项、身份不符、部分成功和整批失败，不以其他资料字段判断昵称是否成功。
- [x] 2.2 让普通状态检查和自动补封面不再写昵称；添加、导入与单项手动刷新使用一致的成功与失败规则。验证缺名未锁、封面可补、直播确认与通知无回归。
- [x] 2.3 统一按到期与强制刷新的分批执行及条件写入，支持重启、取消及后台延迟；用混合结果验证只重试失败项，用在途改名、删除恢复与维护验证过期结果被拒绝。

## 3. 用户入口与回归

- [x] 3.1 设置页提供两个可编辑间隔和全量按钮，展示进度和成功／待重试／跳过数；验证无登录、暂停、筛选、无目标、连点及非法输入。
