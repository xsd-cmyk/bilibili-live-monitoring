#  icons/names.txt —— 「应用名称」轴的唯一事实源（UTF-8）

#  格式（一行一个名字；改完重跑 tools\generate-icon-presets.ps1 或直接 .\build-and-install.ps1）：
#    · 一行一个名字；行首尾空白会被去掉
#    · # 开头的行 = 注释，整行忽略
#    · 空行忽略
#    · 重复名只保留第一次出现（去重不看大小写：CCTV 与 cctv 在桌面上分不开）
#    · 名字里不能有 |（它是 res/values/icon_presets.xml 里矩阵/轴的字段分隔符）或制表符；
#      有的话脚本会报错并逐条列出（不静默丢弃）
#    · 名字里的 & < > " 会被自动 XML 转义，可以放心用
#
#  编号：第 j 个有效行 = 名称档 j（j 从 1 开始）。
#    j = 0 是哨兵 = 应用自己的名字（@string/app_name），不写在这里。
#    组件名 IconPreset_<i>_<j> 里的 j 就是这个编号。
#
#  这个文件不存在、或者里面全是注释/空行 —— 都是正常状态：M=0，
#  脚本会退化成「只有图标轴」，仍然生成 IconPreset_i_0 这些别名，不报错。
#
#  ★ 新增 / 改名 / 删名都必须重装 APK（adb install -r，应用数据保留）：
#    别名的 android:label 是清单里的组件属性，只能随 APK 一起进系统。
